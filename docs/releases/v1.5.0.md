## New in 1.5.0

- Choose **16-bit PCM**, **24-bit PCM**, or **32-bit float** for WAV; FLAC offers **16-bit** and **24-bit PCM**. **Auto** keeps the previous export behavior, and MP3 is unchanged.
- Use **Import model…** to add a compatible BS-Roformer or Mel-Band Roformer `.ckpt` and its matching YAML from disk. The app keeps a private copy. This supports the normalized-STFT Mel-Band configuration used by Gabox's Flowers V10.
- Use **Quality → Advanced…** to tune segment size and overlap, plus batch size for MLX Roformer/MDXC models. **Balanced** starts those models at 256 frames, overlap count 4, and batch size 1. Model families with different controls show their own options.
- Includes configurable Hugging Face discovery sources and the HyperACE v2 and SCNet CPU models added since the previous release.

Download the macOS ARM64 ZIP for an Apple Silicon Mac running macOS 15 or later. See the [installation instructions](https://github.com/fdebkowski/mlx-audio-separator-gui#install) for first launch.
