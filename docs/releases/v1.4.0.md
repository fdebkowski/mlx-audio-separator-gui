## What's new

- **Automatic model-catalog refreshes.** Compatible model metadata and published SDR measurements refresh daily, with an immediate **Refresh list** action and the last working catalog retained offline. Model weights still download only when needed.
- **Four-stem separation choices.** A **4 stems** filter finds vocals/drums/bass/other models. Adds ZFTurbo BS Roformer MUSDB18HQ, SYH four-stem FT, and an SW mode that folds guitar and piano into Other before output encoding. SW shares its download with the six-stem model and supports Other-only output.
- **More useful quality information.** Adds sourced measurements for previously blank entries. Multi-stem quality uses the mean of reported stems. Right-click **Quality and model details** for per-stem SDR, benchmark and source links. Compare scores from the same benchmark; the SW fold-down has no independently measured score.

## Fixes

- **ZFTurbo Mel-Band-RoFormer Vocals v1 works in the bundled app.** The engine is pinned to 0.1.20, the native MLX model appears after catalog migration, and nested weight/config downloads are recognized, revealed and deleted correctly.
- Hugging Face checkpoint/config pairs use the same repository revision. Ambiguous pairs and unsupported custom architectures are excluded from discovery.
- Release builds fail on signing or dependency errors. The final extracted ZIP is checked before publication, including its frozen version, bundled dependencies, native binaries, signature and basic separation output.

## Install

1. Download **MLX-Audio-Separator-1.4.0-macos-arm64.zip** from this release.
2. Unzip and drag **MLX Audio Separator.app** to `/Applications`.
3. This build is ad-hoc signed, without Apple notarization. After checking the download's origin and checksum, clear its quarantine if macOS blocks launch:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/MLX Audio Separator.app"
   ```

Requires an **Apple Silicon Mac (M1 or newer), macOS 15 or later**. Python, the separation engine, FFmpeg and FFprobe are bundled. First use of a model needs an internet connection; cached models work offline.

## Verification and scope

`SHA256SUMS` verifies the ZIP. `validation.json` records checks performed against the extracted release artifact, including deterministic eight-second, 24-bit stereo input separated with ZFTurbo Vocals v1, the added ZFTurbo and SYH four-stem models, and SW four-stem/Other-only output. These are functionality checks, not a full-dataset quality benchmark or a listening evaluation.

`source-commit.txt`, `build-platform.txt` and `build-requirements.txt` identify the source and resolved build environment. The bundled static FFmpeg/FFprobe are from eugeneware/ffmpeg-static b6.1.1; their GPL v3 license and source information are in `Contents/Resources/ffmpeg/`.
